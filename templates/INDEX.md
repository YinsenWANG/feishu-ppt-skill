# Cherry Studio PPT 模板库 · 51 页场景索引

> 每个模板 = 一个可复用的飞书幻灯片布局 XML（960×540）。
> 用法：按场景选版 → 使用 `scripts/template_fields.py prepare` 生成字段草稿 → 填写真实内容 → `scripts/validate.py` 校验 → 截图与内容检查。详细操作见 [模板准备](../references/template-authoring.md)。模板包含示例内容，不能直接视为完成稿。
> 模板预览：[总览图](../docs/template-preview-hd.jpg) · [逐页 SVG](../docs/preview/)（与当前模板同步，近似预览）

## 封面 / 转场 / 封底（P1-P6, P51）

### P01 封面 · 左对齐大标题
- **适用**：招商方案、汇报材料的正式封面
- **结构**：左上 Logo + 左对齐大标题（2 行）+ 副标题 + 珊瑚红短线 + CTA
- **适合内容**：方案名称、一句话价值主张、日期/材料属性
- **示例**："Cherry Studio 一体机合作方案"
- **替换**：`让每一次表达，都更接近行动。` → 你的主标题；副标题 → 材料说明

### P02 封面 · 产品截图
- **适用**：产品发布会、新品介绍的封面
- **结构**：左上 Logo + 左对齐标题 + 右侧产品截图直接展示
- **适合内容**：产品名、版本号、产品愿景
- **示例**："Cherry Studio 3.0"
- **替换**：占位图片换成真实产品截图，按实际宽高比调整尺寸，保持左上角对齐；不叠加窗口外框或模拟界面

### P03 章节 · 编号转场
- **适用**：长文档的章节分隔页（每章开头）
- **结构**：白底 + 珊瑚红大编号 + 章节标题 + 副标题 + 短线
- **适合内容**："01 / 市场机会" 这类章节名
- **示例**：03 · 从洞察，到行动
- **替换**：`03` 改章节号；`从洞察，到行动` 改章节名；副标题改章节说明

### P04 方案 · 三栏核心
- **适用**：方案总览页（一页讲清方案三要素）
- **结构**：标题 + 三张彩色顶条卡（定位/交付/节奏）+ 每卡占位说明
- **适合内容**：方案的 3 个关键维度（定位、交付物、时间节奏）
- **替换**：三卡标题+说明 → 你的方案要素

### P05 转场 · 装饰彩点
- **适用**：风格化转场页（需要视觉过渡时）
- **结构**：居中标题 + 副标题 + 珊瑚红短线 + 5 色圆点（品牌色点缀）
- **适合内容**：一个过渡金句
- **示例**："清晰，是一切行动的起点。"
- **替换**：标题/副标题 → 你的过渡语

### P06 封底 · CTA
- **适用**：招商材料、提案的结尾（号召行动）
- **结构**：标题 + 副标题 + 白底描边 CTA 按钮 + 联系方式
- **适合内容**："让我们开始" + 联系邮箱
- **替换**：CTA 文字/邮箱 → 你的联系方式

### P51 封底 · 谢谢观看
> 收尾页允许较多留白。按实际任务决定是否使用；仍需完成统一校验与截图检查，不为填满页面添加无关内容。
- **适用**：任何正式汇报的收尾页
- **结构**：居中大 Logo + "谢谢观看" + 珊瑚红短线 + 品牌语 + 邮箱 + 年份
- **适合内容**：通用结束页
- **替换**：品牌语/邮箱/年份

## 目录 / 导航（P7-P9）

### P07 目录 · 编号列表
- **适用**：正式材料的分节目录（编号 01-05）
- **结构**：左对齐编号列表（大编号 + 章节名 + 说明）
- **适合内容**：5 个章节的标题 + 一句话摘要
- **替换**：编号/章节名/说明

### P08 目录 · 卡片网格
- **适用**：视觉化目录（卡片式导航）
- **结构**：3×2 卡片网格（每卡：编号 + 名称 + 简述）
- **适合内容**：6 个章节或 6 个主题
- **替换**：卡内文字

### P09 导航 · 进度条
- **适用**：带进度感的分节导航（如 02/05）
- **结构**：大号当前章节号 + 进度条 + 章节列表
- **适合内容**：长 deck 的分节定位
- **替换**：章节号/进度

## 文本 / 论证（P10-P17）

### P10 正文 · 单栏观点
- **适用**：一页一个核心观点的论述页
- **结构**：居中标题 + 居中正文 + 底部结论条
- **适合内容**：方法论、观点阐述
- **替换**：标题/正文/结论

### P11 正文 · 左右分栏
- **适用**：左右对照的内容页（左概述右细节/步骤）
- **结构**：左栏标题+说明+路径，右栏 3 条步骤卡
- **适合内容**："把信息组织成行动路径"类内容
- **替换**：左栏文字、右栏 3 条（01 输入/02 判断/03 行动）

### P12 论证 · 金字塔
- **适用**：结论先行的论证页（结论→3 个证据）
- **结构**：顶部结论条 + 三张证据卡
- **适合内容**："先结论，再证据"的汇报逻辑
- **替换**：结论 + 3 证据

### P13 论证 · 问题方案
- **适用**：问题→方案型论证
- **结构**：左右对比（问题 | 方案）
- **适合内容**：痛点分析、解决方案
- **替换**：问题列表/方案列表

### P14 论证 · 引证引用
- **适用**：引用名言、客户语录、原则宣贯
- **结构**：大号引文 + 来源署名
- **适合内容**：公司原则、名人引用、客户证言
- **替换**：引文 + 署名

### P15 论证 · 三支柱
- **适用**：增长/能力的三个支柱
- **结构**：标题 + 三张等权卡（支柱名 + 说明）
- **适合内容**："增长来自三个支柱"类框架
- **替换**：三支柱名称 + 说明

### P16 步骤 · 2×2 卡片（编号徽章）
- **适用**：四步方法论、执行步骤
- **结构**：标题 + 2×2 卡片网格（每卡：珊瑚红编号徽章 40×40 + 标题 + 说明）
- **适合内容**："四步把共识变成结果"类流程要点
- **替换**：4 张卡片的编号/标题/说明
- **注意**：卡片化布局，区别于目录的竖排编号列表；**无底部结论条**

### P17 列表 · 图标要点
- **适用**：带图标的能力/要点列表
- **结构**：3 项（图标 66×66 + 标题 + 说明）+ 底部结论条
- **适合内容**：三项核心能力
- **替换**：图标文字/标题/说明/结论条

## 数据 / 图表（P18-P25）

### P18 数据 · 单一大数字
- **适用**：强调单个关键数字（业绩、规模）
- **结构**：超大数字 + 单位/说明 + 补充语
- **适合内容**："50,000+ 次创作"类核心指标
- **替换**：数字 + 单位 + 说明

### P19 数据 · 四宫格指标
- **适用**：4 个关键指标的并列展示
- **结构**：2×2 指标卡（大数字 + 标签）
- **适合内容**：月报核心指标（用户/收入/留存/转化）
- **替换**：4 个指标

### P20 数据 · 指标对比
- **适用**：前后对比、同比环比
- **结构**：左右对比卡（旧 vs 新 / 今年 vs 去年）
- **适合内容**："改变，清晰可见"类对比
- **替换**：两组指标

### P21 图表 · 柱状图
- **适用**：分类对比、增长趋势（柱状）
- **结构**：原生柱状图 + 标题 + 数据来源
- **适合内容**：月度活跃用户、季度营收
- **替换**：`chartField` 数据（dim1 分类 + dim2 数值）

### P22 图表 · 折线趋势
- **适用**：连续趋势、留存曲线
- **结构**：原生折线图 + 标题
- **适合内容**："用户留存进入稳定区间"类趋势
- **替换**：chartField 数据

### P23 图表 · 饼图占比
- **适用**：构成比例分析
- **结构**：原生饼图 + 右侧说明（大数字+结论）
- **适合内容**：用户来源、收入结构
- **⚠️ 坑**：饼图标签短（≤3 字，如"自然"而非"自然增长"），否则被截断
- **替换**：dim1 分类 + dim2 占比 + 右侧结论

### P24 图表 · 双图表 + 结论
- **适用**：两个关联指标同页展示
- **结构**：左右两个图表 + 底部关键结论条
- **适合内容**："增长与留存同步改善"类关联分析
- **替换**：两个 chartField + 结论

### P25 数据 · 表格对比
- **适用**：结构化方案对比（多维度）
- **结构**：原生表格（维度 × 方案列）
- **适合内容**：功能对比、价格对比
- **替换**：表格单元格内容

## 流程 / 架构（P26-P32）

### P26 流程 · 横向四步
- **适用**：四步流程（横向）
- **结构**：4 张步骤卡（编号 01-04 + 名称 + 说明）+ 连接线 + 底部统一原则条
- **适合内容**："识别问题→制定方案→协同执行→复盘迭代"
- **替换**：4 步名称/说明 + 原则条

### P27 流程 · 纵向时间线
- **适用**：时间顺序的事件/里程碑（纵向）
- **结构**：左侧时间刻度 + 右侧事件卡
- **适合内容**："09:00 晨会"类日程、项目时间线
- **替换**：时间 + 事件

### P28 流程 · 循环闭环
- **适用**：循环流程（PDCA、持续迭代）
- **结构**：环形闭环 + 4 个阶段节点
- **适合内容**："持续增长"循环、敏捷迭代
- **替换**：阶段名/说明

### P29 架构 · 层级结构
- **适用**：组织/系统层级（决策层→执行层）
- **结构**：自上而下层级卡
- **适合内容**：组织架构、系统分层
- **替换**：层级名称

### P30 架构 · 核心与能力
- **适用**：一个核心入口关联四个同级能力，空间方向没有额外含义
- **结构**：左侧浅珊瑚色核心主卡 + 右侧统一浅灰面板内的 2×2 能力卡；通过分组与层级表达关联
- **适合内容**："以核心能力连接四个关键模块"
- **替换**：观点标题、辅助说明、核心名称/说明、4 模块名/说明；能力保持同等权重，不用彩虹描边或顺序编号

### P31 架构 · 输入输出
- **适用**：管线/处理流程（输入→处理→输出）
- **结构**：左右输入/输出 + 中间处理区
- **适合内容**：数据处理流程、产品管线
- **替换**：输入/处理/输出内容

### P32 流程 · 泳道分工
- **适用**：多角色协作流程（泳道图）
- **结构**：两条泳道（角色 A/B）+ 各泳道任务卡
- **适合内容**：跨角色工作流（产品/研发/市场）
- **替换**：角色名 + 任务卡

## 产品 / 方案（P33-P38）

### P33 产品 · 截图+要点
- **适用**：产品介绍（左截图右要点）
- **结构**：左侧产品截图直接展示 + 右侧 3-4 条要点
- **适合内容**：产品功能亮点
- **替换**：截图 + 要点；按截图实际宽高比调整尺寸，不叠加窗口外框或模拟界面

### P34 产品 · 功能矩阵
- **适用**：功能全景（多维度）
- **结构**：功能分类矩阵（对话/协作/智能体等）
- **适合内容**：产品能力地图
- **替换**：功能项

### P35 方案 · 问题解决
- **适用**：痛点→方案对照
- **结构**：当前痛点 vs 解决方案
- **适合内容**："用户痛点 → 我们的解法"
- **替换**：痛点/方案

### P36 方案 · 对比表
- **适用**：多方案多维度对比（含星级）
- **结构**：原生表格（维度 × 方案）+ 星级评价
- **适合内容**：竞品对比、套餐对比
- **⚠️ 坑**：表格颜色用纯色 rgba(255,255,255,1)，勿用半透明
- **替换**：维度/方案/星级

### P37 方案 · ROI 计算
- **适用**：投入产出分析
- **结构**：投入/产出/ROI 计算卡
- **适合内容**："投入 X 产出 Y 回报 Z"类计算
- **替换**：数字/说明

### P38 案例 · 客户故事
- **适用**：客户案例、用户证言
- **结构**：左引文 + 右头像/姓名/职位
- **适合内容**："客户的改变，是最有力的证明"
- **替换**：引文 + 头像占位 + 姓名职位
